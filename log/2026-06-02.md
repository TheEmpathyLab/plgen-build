## Decisions made

- **v1.2 not v1.3** — GPT system prompt versioning (v3.3) is implementation-level and doesn't map to spec versioning. Spec tracks format changes only.
- **Prompt-first for mid/done paths** — directing mid-work users to open a separate PLGen project is bad UX; they paste a prompt in their existing session instead, with install as the upgrade path
- **/.copy-pre as a named component** — inline overrides fighting shared.css rules are a signal that shared.css is missing a component; added the class rather than patching the symptom
- **Issue #27 for remaining audit** — one CSS fix surfaced a broader pattern; logged as a tracked issue rather than blocking this session
