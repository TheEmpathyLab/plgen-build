# Session Log — 2026-06-03

**Focus:** /start and /install refinements, CSS refactor, accessibility, Miro AI discovery

## What was built

### /start — project vs. standalone choice
- Identified that directing mid-work users to "Open PLGen in Claude" was wrong UX — they're already working somewhere
- Added `.choice-cards` / `.choice-card` component to shared.css
- new + claude and new + chatgpt paths: two-card setup choice — "Your own project or CoWork" (→ /install) vs. "One-off work" (→ standalone PLGen)
- mid + claude and mid + chatgpt: replaced single "Install PLGen" CTA with two-card choice at the bottom of each path
- Confirmed: the standalone PLGen Claude Project is private per user — each person gets their own conversation, Shelton's sessions are not visible

### CSS refactor — copy-pre component
- Root cause: shared.css sets `pre` globally to light cream text on dark background; light-background prompt blocks inherited invisible text
- Added `.copy-wrap`, `.copy-pre`, `.copy-pre-scroll` as proper components to shared.css
- Removed `.prompt-wrap pre` override and redundant `.copy-btn` redefinition from /install page `<style>` block
- Replaced all inline-styled wrappers, pres, and buttons on /start with classes
- Established rule: inline style overrides on shared.css elements signal a missing component

### Accessibility — font size floor
- Audited all font-size declarations across shared.css
- Smallest found: 9px (required/optional badges), 10px (phil-label, example-label), 0.7em (pl-mark)
- Bumped: 9px → 11px, 10px → 12px, h2 and hero-eyebrow 11px → 12px, pl-mark 0.7em → 0.8em
- Nothing smaller than 11px anywhere in the design system now
- Intentional 11px UI text (buttons, toggles) left unchanged

### GitHub issue
- Opened issue #27 for broader CSS audit — inline styles, shared.css assumptions, nav/footer consistency

## Decisions made

- **Prompt-first for mid/done paths** — paste prompt in current session rather than switching tools; install and standalone options surfaced as follow-up CTAs
- **choice-cards as a shared component** — not page-specific; went into shared.css immediately
- **Spec field audit deferred** — identified that human_role, ai_role, work_title, estimated, session_init exist in the implementation (system prompt + register form) but not in the spec's optional fields table; held off updating the spec
- **Font floor at 11px** — hard minimum for all readable text; UI chrome (buttons, toggles) can stay at 11px

## Issues encountered

- Invisible text on /install pre blocks — light text on light background from shared.css global rule; fixed by adding `color: var(--black)` then properly refactored into `.copy-pre`
- Inline styles were fighting shared.css rules in two pages — resolved by refactoring into components

### New discovery — Miro Sidekick
Miro's internal AI (Sidekick) generated a Provenance Label when asked, citing provenancelabel.org. The output was verbose and non-standard — dimensional breakdown (Ideation/Creation/Editing/Formatting) rather than the short/long PLGen format. PLGen has no resources for embedded AI tools like Miro, Notion AI, or Gemini in Docs. This is a gap to think about.
